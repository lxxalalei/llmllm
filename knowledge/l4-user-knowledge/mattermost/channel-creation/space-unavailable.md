# 为什么我不能创建 Space？

Space 依赖 Docs 功能能力，并且不使用普通团队频道的标准创建入口。相关能力未开启时，Space 创建会被拒绝。

> 草稿：等待产品确认实际用户入口和文案后才能发布。
